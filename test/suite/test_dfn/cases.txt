# test_dfn cases: one per line,  name | mesh | arguments | what it does
#
# Each case runs, in work/NAME,  del_vor -avs MESH ARGUMENTS -report NAME.report
# A mesh path starting with gen/ is made by make_dfn_inputs.py; inputs/
# holds Carl's DFN example when it has been added (else that case is
# SKIPPED).
#
dfn3       | gen/dfn3.inp | -stor dfn3.stor -uge dfn3.uge | Three fractures: 1 (z = 0.5, oriented with its normal along -z) and 2 (x = 0.5, normal +x) cross along a line of 16 edges, each shared by 2 triangles of each fracture; 3 is tilted 30 degrees and meets nothing. Checked against exact arithmetic: every edge paired within its own fracture, 16 intersection edges, no violation. Every coefficient and control area is checked against the cotangent formula summed over all triangles, so an intersection edge's coefficient is the sum of both fractures' contributions, and the areas add up to the fractures' area.
dfn3_flip  | gen/dfn3_flip.inp | -stor dfn3_flip.stor | The same network with one triangle of fracture 2 turned over: neighbors in that fracture now run along a shared edge the same way. Must stop (exit 1) with the orientation error naming the triangle, and write nothing.
full_mesh  | inputs/full_mesh.inp | -stor full_mesh.stor | Carl's 4-fracture dfnWorks example (771 vertices, 1386 triangles; fractures 1 and 3 face +z, 4 faces -z): no violation, 60 intersection edges, 1942 interior edge instances, as found while writing the design.
