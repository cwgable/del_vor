# delaunay_fatal (default 1e-2): delta/L between -delaunay_fatal and
# -delaunay_tol is a warning; below -delaunay_fatal, fatal.
#
# Each case runs, in work/NAME,
#   del_vor -avs MESH -check_only on -violations NAME.vtu -report NAME.report EXTRA
# (EXTRA may override check_only). A mesh path starting with gen/ is made by
# make_delaunay_inputs.py; the others are inputs of other suites. The
# expected results are worked out by check_delaunay.py with exact
# arithmetic (../exact_check.py), not stored here.
#
